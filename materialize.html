Styling with Materialize

This page demonstrates Materialize CSS components. It includes buttons, cards, a styled table, a circular image, materialboxed images, and a video embed.

About

Materialize is a responsive front end framework based on Material Design. For this page, I adapted its components to fit the darker editorial look of Grego Gallery rather than using the default bright palette to make the page feel more consistent with the rest of the site.

The sections below display a few useful interface patterns including buttons, image cards, a highlighted panel, a circular profile style image, and a responsive embedded video. Each component has been customized to support the tone of a my portfolio instead of our generic demo page.

Embedded Video

This section demonstrates responsive video embedding using a locally hosted file. Unlike external embeds, this ensures we keep full control over the content we publish.

The vertical format (9:16) is industry standard for social media video, Materialize's responsive container ensures it scales properly on all screen sizes while keeping the video as the focal point.
